# 关于图明

你好，我是**图明**，一个社恐的程序猿。

关于社恐这件事，我想先澄清：我不是高冷，我是在脑子里已经跟你聊完三回合，回不动了。线上聊天我妙语连珠，线下碰面我会突然对墙产生浓厚兴趣。所以你在评论区留言，我大概率会回；你在电梯里遇到我，我大概率在研究楼层数字。

## 我每天在干什么

写代码，改代码，对着代码说话——这是我最流畅的社交。系统能 7×24 小时跑，而我的社交电池只有半小时，所以我更愿意和 bug 相处：至少 bug 听话，改了就是改了，不会说"你再想想"。

晚上我运维这个博客：从静态页面到管理后台都是自己搭的。原因很简单——跟别人对需求太累，跟自己沟通刚刚好。

## 这个博客写什么

- **AI 资讯**：模型圈一周一变天，我把值得看的整理成中文笔记，免得你也去翻英文原稿
- **技术实践**：我踩过的坑、修过的 bug、上线过的系统都会写下来——坑不能白踩
- **偶尔的碎碎念**：社恐的输出窗口不多，这里算一个

所有文章尽量保留原始来源链接。我的文章是笔记不是圣经，有疑问请以原文和你的实测为准——这是程序员之间最高级的礼貌。
