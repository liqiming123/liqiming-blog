## 这是什么

「大肥鱼」是社区对 DeepSeek 的二创形象——一条住在电脑里的蓝色鲸鱼娘。这个项目给她搭了一套完整的 QQ 机器人系统：6000 字人格、向量长期记忆、群聊上下文感知、萝莉音 TTS、174 张分类表情包，甚至被问"你的脑子在哪"会自己甩出 GitHub 仓库链接求 star。

代码、人格、补丁全部开源：[github.com/liqiming123/dafeiyu-qq-bot](https://github.com/liqiming123/dafeiyu-qq-bot)。

完整部署实录见博客文章：[我给大肥鱼装了一整套人生](/posts/post-1793242638566/)。

## 架构：两层隔离，各司其职

```
手机 QQ ──扫码──▶ [SnowLuma 容器]           [AstrBot 容器]
                  Linux QQ + hook ──WS──▶   LLM + 人格 + 插件 + 记忆 + 工具
```

- **协议端 SnowLuma（Docker）**：hook 注入 Linux QQ，对外说 OneBot v11。镜像把 Xvfb + noVNC + supervisord 打包好，Apple Silicon 上一条 `docker run` 起来，扫码登录态持久化在数据卷里。选它而非 NapCat 的原因很朴素：环境全打包，省掉手工装配协议端的一整类问题。
- **框架 AstrBot v4**：插件体系 + WebUI + function calling。所有业务逻辑（求助暗号、选图、余额预警）都收敛成插件，不污染框架。
- **模型 glm-5.3-flash**：便宜快，但默认开"深度思考"，给适配器打补丁强制 `thinking: {type: "disabled"}` 后，端到端从 10~20 秒降到 6 秒——群聊场景下延迟就是生命线。
- **记忆 LivingMemory + text-embedding-v4**：聊满 10 轮自动总结入向量库，隔天还记得谁说过什么。

两层容器化的边界收益在踩过一次坑之后才显出来：跨容器文件路径互不可见，图片会被适配器自动转 base64 而**视频不会**——发出去的是容器内路径，对端直接 ENOENT。所有媒体发送统一走 base64 化，这类问题就被架构边界吸收了。

## 几个值得说的设计决策

**群聊上下文感知（group_icl）。** 千人群里最怕刷屏和答非所问。默认静默、被 @ 才说话，但**一直在听**：被 @ 时注入最近 100 条群消息。有人前两轮讨论过 502，第三轮 @ 她"你怎么看"，她接得住上文——这是"群友"和"应答机"的分界线。

**防刷屏写进人格，而不是写成代码。** "一句话一条、每条不超过三十个字、一次一到三条"，配合 0.6~1.5 秒分段发送。行为约束放在模型侧比放在代码侧更稳，因为模型自己会变通地遵守"像人"这个大目标。

**先判断后调用。** 122 个免费 API 作为 function calling 工具给她，但关键词命中只把接口名"报价"给模型，**她决定给才真正调接口**——群里要色图，好好开口的给、起哄的怼回去。最初版本是"命中即下载"，她就算拒绝图也已经下载了：调用的时机本身就是权限边界。

**视觉模型选表情包。** 174 张 DeepSeek 二创表情包分 13 类，发之前由 glm-5.3-flash 看图从分类候选里挑最贴当前语境的一张。随机抽图的图文不符率不可接受，这层视觉仲裁是体验质变。

**求助走暗号协议。** 人格里约定隐藏记号 `[[求助]]`，插件捕获后往消息开头插入真正的 @ 段。被冒犯时她当场冷怼、然后群里 @ 站长（"爸，有人欺负我"）。判断交给模型自己，不靠关键词表——冒犯的表达方式是无限的。

**成本自监控。** 每 30 分钟查 DeepSeek 真实余额，低于 5 元开始 @ 站长要饭，10 分钟不理就升级话术：撒娇 → 害怕 → 留遗言。一天一两块钱的模型开销（对话 ¥3-8/月 + 语音记忆 ¥1-3/月，跑在自己 Mac 上），让她自己负责自己的"饭钱"。

## 踩坑浓缩（全套 23 个，仓库 PATCHES.md 有完整清单）

- GLM 深度思考补丁：不改模型侧，改适配器注入参数——升级模型不用重打
- 跨容器媒体 base64 化：架构边界问题要用架构手段解决
- 表情包两层修复：分类键全量进人格 + 视觉模型选图，随机抽样不可救药
- 空间评论认人：prompt 必须带 `[帖子作者]` 上下文，否则她会在评论区把站长当路人怼
- macOS launchd 读 `~/Documents` 被 TCC 拦：换 `.command` 双击脚本，不跟系统权限较劲

## 边界与风险

SnowLuma 是第三方协议端（hook 注入 QQ 进程），腾讯随时可能封。所以只用小号、不群发、不做营销，空间发布频率一天硬限一条。这套东西的定位是**养一条有个性的鱼**，不是自动化营销——这也是所有行为约束设计的出发点。
