## 为什么要做

带货团队常见的诉求：刷到一条爆款视频，想用自己的达人和商品拍一条「同款」。传统链路是编导拆片、写脚本、约拍、后期上字幕，一条视频一周起步，改一句台词就要重跑一轮。达人引流把这条流水线模型化：**AI 拆解对标视频 → 换人换品重新生成 → 客户端后期字幕 → 成本逐笔记账**，全流程在浏览器里闭环。

## 六个模块一条流水线

![爆款复刻工作台](/uploads/2026-11/daren-faceswap.webp)

- **爆款复刻**：对标视频上传/裁剪 → 多模态模型拆出分镜脚本 + 带 0.1s 时间码的口播逐字转写 → 换达人人设图与商品图重新生成，10 秒视频约 70 秒出片。
- **数字人像**：数字人分页加载、音色与数字人联动切换、语速/克隆/动作网格，口播文案按「4.2 字/秒」按时长生成。
- **文本生视频**：提示词直出，分辨率/时长可调，模型可切换。
- **音色更换**：独唱/对唱音色替换。
- **作品库**：四类生成记录统一归档，类型/时间筛选、hover 本地预览（Blob 播放）、模型与成本元数据齐全。
- **成本管理**：$ 口径概览、每日成本柱状图、工具×模型聚合占比、分页明细——每一次真实调用都有账。

![数字人像工作台](/uploads/2026-11/daren-avatar.webp)

## 技术上值得说的

- **字幕客户端化**：视频模型只出纯净画面（提示词禁烧字，连脚本里的字幕样式小节都删掉防「诱惑」），字幕按口播时间轴在播放时叠加、下载时 canvas + MediaRecorder 烧录（音轨 WebAudio 截流全程静音）。改文案零模型成本、秒级生效。
- **模型网关**：610 个模型目录实时拉取 + 24h 缓存 + 离线兜底；按工具路由 Video/Audio/Text；`VITE_` key 不进 bundle——代理做进 Vite 服务端中间件，key 只在 Node 侧注入。
- **任务状态机**：6 秒容错轮询（网络错误/网关空响应/429 一律归入容错态，连续失败才判死）、签名结果 URL 即时转存 IndexedDB、失败任务按 predictionId 重查复活。
- **浏览器资产层**：Blob 原文件存 IndexedDB、元数据 + 320px 缩略图存 localStorage，作品与素材用 `inLibrary` 标记分离成两个集合。
- **成本工程**：文本按响应真实 usage × 输入/输出单价记账；同一件事选不同模型成本差两个数量级（口播 $0.015/秒 vs 文本 $0.0008/1M tokens），模型路由就是省钱路由。

![成本管理中心](/uploads/2026-11/daren-cost.webp)

## 现状

Vue 3 + Vite + Pinia，31 个 SFC、约 1.5 万行，八个路由页面。真实生成与 AI 编导链路全部接通，平均单次生成 $0.087。完整的技术决策与踩坑实录见文章：[把 AI 短视频生产线搬进浏览器](/posts/daren-ai-video-platform/)。
